# היסטולוגיה של מערכת השתן – סיכום לבוחן

דף לימוד ממוקד לבוחן בהיסטולוגיה של הכליה ודרכי השתן (Junqueira פרק 19), בנוי מרשימת המושגים של הקורס ומשתי מצגות ההרצאה.

- `index.html` – הסיכום: תמונה גדולה, "המסע של השתן" תחנה אחרי תחנה (16 תחנות, דיאגרמת רכבת תחתית בצבעי אפיתל), גופיף ומחסום סינון, טבלת זיהוי צינוריות, JGA ו-RAAS, צינור מאסף, אספקת דם, דרכי השתן ואורותל, מפת האפיתל, סיכום הקורס, קליניקה, וכל הטריקים לזכירה.
- `quiz.html` – 30 שאלות ברירה עם משוב והסבר, סינון לפי נושא, ערבוב וציון.
- `img/` – תמונות מהמצגות (Junqueira) ומחומרי הקורס. לשימוש לימודי אישי בלבד.

קבצים סטטיים, ללא תלויות, עובדים אופליין. לחיצה על תמונה פותחת אותה בגדול.
